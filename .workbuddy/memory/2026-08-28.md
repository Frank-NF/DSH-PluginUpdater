## 关键坑
1. **数据库路径**：构建产物 db.mjs 写死 `join(process.cwd(), "..", "..", ".data")` → 实际库在 **`/var/.data/dsh-website.db`**，`DSH_DB_PATH` 环境变量不生效。排查技巧：`/proc/<pid>/fd` 看进程打开的 .db 文件。
2. **GitHub OAuth 未配置时** `/api/auth/github` 返回 503（预期行为），需配置 `GITHUB_CLIENT_ID`/`GITHUB_CLIENT_SECRET` 环境变量 + 在 GitHub 创建 OAuth App（回调地址 `http://64.90.30.139:8072/api/auth/github/callback`）。
